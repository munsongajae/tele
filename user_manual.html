Telegram Channel Reader 사용자 매뉴얼

이 문서는 Telegram Channel Reader (텔레그램 채널 리더) 프로그램을 처음 접하는 일반 사용자를 위한 상세 가이드입니다.

1. 프로그램 소개

Telegram Channel Reader는 사용자가 구독 중이거나 관심 있는 텔레그램 공개 채널의 포스팅을 가져와 편리하게 읽고 검색하며, 로컬 폴더에 저장할 수 있도록 돕는 독립형 데스크톱 웹 애플리케이션입니다.

  • 무설정 구동: 별도의 파이썬(Python) 엔진 설치 없이 실행 파일(app.exe) 더블클릭만으로 즉시 구동됩니다.
  • 로컬 데이터 보존: 사용자의 API 키와 텔레그램 세션 정보는 사용자의 개인 PC 외부로 절대 유출되지 않고 로컬 DB에 안전하게 암호화되어 저장됩니다.

2. 사전 준비: 텔레그램 API 키 발급 절차 (최초 1회)

텔레그램 서버는 보안을 위해 타사 앱을 통한 접속 시 고유한 개발자 API 키를 요구합니다. 아래 순서대로 쉽게 발급받을 수 있습니다.

  1. 로그인 사이트 접속
    • 웹 브라우저를 열고 https://my.telegram.org에 접속합니다.
  2. 전화번호 로그인
    • Your Phone Number 칸에 국가코드를 포함한 본인의 텔레그램 가입 전화번호를 입력합니다. (예: 대한민국 국가코드 +82를 포함해 +821012345678 입력)
    • Next를 누르면, 본인의 스마트폰/PC 텔레그램 공식 앱으로 로그인 인증 코드가 전송됩니다.
    • 전송받은 코드를 웹 화면의 Confirmation code 칸에 입력하고 Sign In을 클릭합니다.
  3. 앱 개발 도구 페이지로 이동
    • 로그인 후 나타나는 메뉴 중 API development tools를 클릭합니다.
  4. App 키 생성 신청
    • 아래 공란들을 작성합니다. (임의의 영문 문자열을 작성해도 상관없습니다.)
      • App title: 프로그램 이름 (예: MyTelegramReader)
      • App short name: 짧은 이름 (예: myreader)
    • 작성 완료 후 하단의 Create application 버튼을 누릅니다.
  5. API ID 및 API Hash 복사
    • 성공적으로 생성되면 노란색 박스 안에 다음과 같은 두 개의 정보가 나타납니다.
      • App api_id: 8자리 내외의 숫자 (예: 12345678)
      • App api_hash: 32자리의 영문/숫자 혼합 값 (예: a1b2c3d4e5f6g7h8...)
    • 이 두 값을 메모장 등에 안전하게 복사해 둡니다.

3. 프로그램 설치 및 실행 방법

  1. 파일 다운로드
    • 전달받은 app.exe 파일을 본인이 사용하기 편리한 폴더(예: C:\TelegramReader 등)에 넣어둡니다.
  2. 바탕화면에 바로가기 만들기
    • 매번 폴더를 찾아가기 번거롭다면, app.exe 파일 위에 마우스 커서를 올리고 마우스 우클릭을 합니다.
    • 나타난 메뉴에서 [보내기] ➡️ [바탕 화면에 바로 가기 만들기]를 클릭합니다. (윈도우 11의 경우, 우클릭 후 추가 옵션 표시를 눌러야 보내기가 보일 수 있습니다.)
    • 바탕화면에 새로 만들어진 아이콘의 이름을 원하는 대로(예: 텔레그램 채널 검색기) 수정하여 사용합니다.
  3. 프로그램 실행
    • 바탕화면에 만든 바로가기 아이콘을 더블클릭합니다.
  4. 웹 화면 자동 오픈
    • 실행 후 검은색 터미널(콘솔) 창이 뜨고, 곧이어 **구글 크롬(Chrome) 브라우저**가 자동으로 실행되며 프로그램 메인 화면(http://127.0.0.1:8788)이 나타납니다.
  5. 프로그램 종료 (자동 종료 기능)
    • 작업을 마친 뒤 **크롬 브라우저의 텔레그램 화면(탭)을 그냥 닫으시면 됩니다.**
    • 탭이 닫히면 서버가 이를 감지하고 약 30초 후에 백그라운드 콘솔 창을 **자동으로 종료**합니다.
⚠️ Windows SmartScreen 경고 대처법
프로그램 실행 시 윈도우에서 "Windows의 PC 보호" 경고 팝업이 뜨는 경우가 있습니다. 이는 새로 제작된 개인 실행 파일이라 발생하는 윈도우 보안의 정상적인 필터 작동입니다.
해결 방법: 팝업 내부의 [추가 정보] 글씨를 클릭한 후, 아래에 나타나는 [실행] 버튼을 클릭하시면 정상 기동됩니다.

4. 최초 로그인 및 인증 연동

자동으로 열린 브라우저 화면의 API Session 카드에서 연동을 완료합니다.

  1. 발급받은 App api_id, App api_hash를 각각 칸에 입력합니다.
  2. Phone 입력 칸에 본인의 핸드폰 번호를 국가코드 형식(+8210...)으로 입력합니다.
  3. [Connect] 버튼을 누릅니다.
  4. 인증 코드 및 비밀번호 입력
    • 본인의 텔레그램 앱으로 전달된 5자리 숫자 인증 코드를 화면에 나타난 Login code 칸에 입력합니다.
    • 계정에 2단계 인증(Two-step Verification) 비밀번호를 설정해 두셨다면, 하단의 2FA password 칸에 해당 비밀번호를 추가 입력합니다.
  5. [Verify] 버튼을 클릭합니다.
  6. 연동이 성공하면 화면 상단 상태 메시지가 Authorized로 변경됩니다.

5. 주요 기능 사용법

1) 채널 목록 추가 및 수정 (Settings Panel)

  • 채널 추가: Settings 패널을 펼친 후 [Add Channel]을 클릭해 새로운 입력 행을 만듭니다.
    • Channel ID: 텔레그램 채널의 공유 링크에 포함된 ID를 입력합니다. (예: https://t.me/TasnimNews 이면 TasnimNews 입력)
    • Display Label: 프로그램 내에서 필터링하거나 표시할 이름(예: 타스님 뉴스)을 자유롭게 입력합니다.
  • 저장: 채널 리스트를 수정한 뒤 하단의 [Save Channels] 버튼을 눌러 저장합니다.

2) 검색 및 필터링 기능 (Search Control)

  • Search terms: 검색하려는 키워드를 입력합니다.
    • 여러 개의 키워드를 동시에 개별 검색하고 싶다면 줄바꿈(Enter) 또는 쉼표(,)로 키워드를 구분하여 입력하면 한 번에 순차 검색해 줍니다.
  • Limit: 한 번에 가져올 포스팅의 개수 최대 한도를 지정합니다. (기본값: 30)
  • Date From / Date To: 특정 기간 내의 포스팅만 필터링하고 싶을 때 시작 날짜와 종료 날짜를 지정합니다.
  • Content Filter: 텍스트 형태 외에 동영상, 사진 등의 미디어 속성에 따라 결과를 필터링할 수 있습니다.

3) 결과 다운로드 및 내보내기 (Export & Save)

  • 검색된 포스팅 목록 상단의 [Save to Folder] 버튼을 누르면, 설정된 Download folder 경로로 포스팅 내용이 물리 파일로 내보내기되어 저장됩니다.
  • Download folder 경로는 Settings 패널에서 수정 후 [Save Folder]를 눌러 변경이 가능합니다.

4) 구글 크롬(Chrome) 실시간 번역 기능 활용법

이 프로그램은 외국어로 수집된 텔레그램 글을 손쉽게 이해할 수 있도록 크롬 브라우저 사용에 최적화되어 있습니다.

  1. 포스팅 글 목록이 보이는 크롬 브라우저 화면의 빈 공간(텍스트가 없는 배경 영역)에 마우스 우클릭을 합니다.
  2. 나타나는 팝업 메뉴에서 [한국어(으)로 번역] 항목을 클릭합니다.
  3. 텔레그램 포스팅 내부의 이란어나 기타 외국어 글들이 실시간으로 한국어로 일괄 번역됩니다.
  4. 추가로 포스팅을 더 불러오거나(Load More) 새로 검색(Search)했을 때 번역이 자동으로 해제되면, 다시 빈 화면을 우클릭하여 [한국어(으)로 번역]을 실행해 주세요.

6. 자주 묻는 질문 (FAQ) 및 트러블슈팅

현상 원인 및 해결 방법
인증 코드가 오지 않습니다.
  • 국가코드 형식을 다시 확인해 주세요. 대한민국은 반드시 +8210... 형식이어야 합니다.
  • 문자 메시지(SMS)가 아닌 텔레그램 공식 앱 내부의 대화방으로 발송됩니다. 텔레그램 앱을 열어 확인해 주세요.
"API credentials are not configured" 에러 발생 입력하신 api_id와 api_hash에 스페이스바(공백)나 특수문자가 섞여서 오타가 나지 않았는지 확인하고 다시 입력해 주세요.
백신 프로그램이 파일을 삭제합니다. 패키징 툴(PyInstaller)의 특성으로 백신 오탐지가 발생한 것입니다. 파일은 완전히 안전하므로 백신 설정의 검사 예외(허용 목록)에 추가한 후 사용해 주세요.
