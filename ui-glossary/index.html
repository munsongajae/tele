프론트엔드 핵심 UI 용어 TOP 30 도감

프론트엔드 개발 시 자주 사용하는 핵심 UI 구성 요소의 정의, 활용 방법, 그리고 HTML/CSS/JS로 실제 구현된 인터랙티브 예제를 제공합니다.

01

Button

Input / Action

버튼

사용자가 클릭하여 액션(폼 제출, 모달 열기, 페이지 전환 등)을 유발하는 가장 대표적인 입력 컨트롤입니다. 호버, 액티브, 포커스, 비활성화(disabled), 로딩 중 상태 등을 세심하게 디자인해야 합니다.

02

Input

Input / Form

입력창

텍스트, 숫자, 비밀번호 등을 사용자로부터 직접 입력받는 창입니다. 라벨(Label), 플레이스홀더(Placeholder), 도움말 텍스트(Helper Text), 에러 상태에 따른 필드 변형 등이 고려되어야 합니다.

영문 소문자, 숫자 조합 4~12자 유효하지 않은 입력입니다.

Checkbox

Input / Form

체크박스

여러 옵션 목록 중에서 복수의 항목을 동시에 선택할 수 있도록 해주는 입력 필드입니다. 선택(Checked), 해제(Unchecked), 부분 선택(Indeterminate) 및 비활성화 상태를 표현할 수 있습니다.

04

Radio Button

Input / Form

라디오 버튼

제시된 여러 옵션 중에서 오직 한 가지만 강제하여 선택할 수 있도록 해주는 UI 요소입니다. 동일한 `name` 어트리뷰트 속성으로 묶어 브라우저가 다중 선택을 배제하게 동작시킵니다.

Overlay

모달

Dialog

Overlay

대화상자

모달의 일종으로, 보통 사용자에게 최종 승인이나 경고, 취소 등 명시적인 '결정'을 받아내기 위해 표시되는 메시지성 레이아웃 상자입니다. 긍정/부정 액션 버튼이 강조되어 배치됩니다.

09

Toast

Feedback / Notification

토스트 알림

화면 구석에 스르륵 나타났다가 수 초 이내에 자동으로 사라지는 작고 가벼운 알림 메시지입니다. 흐름을 방해하지 않고 백그라운드 작업 완료(저장됨, 성공 등) 피드백을 전달할 때 최고입니다.

Tooltip

Overlay / Feedback

툴팁

해당 요소 위에 마우스 포인터를 올렸을 때(Hover), 해당 항목의 맥락에 맞춘 부가 설명 텍스트를 담아 조그맣게 띄워주는 미니 설명창입니다. 공간 절약과 쉬운 설명 제공에 유리합니다.
